Interactive Terminal Portfolio

    A browser-based, command-line interface (CLI) portfolio for system programmers.
    No frameworks. No bloat. Just raw code.

About

This project is a minimalist, retro-styled portfolio designed to showcase my skills in Low-Level Programming (C, Assembly) and System Architecture. Instead of a traditional static website, I built an interactive terminal environment that reflects the tools I use daily.

It features a command parser, history navigation, and a CRT monitor aesthetic without relying on heavy external libraries.

Features

    Command-Line Interface: Navigate through my bio and projects using text commands.

    Retro Aesthetics: Custom CSS for a dark, high-contrast terminal look with scanline effects.

    Lightweight: Built with pure HTML, CSS, and Vanilla JavaScript.

    Responsive: Works on desktop and mobile browsers.

Commands

Type help to see the full list. key commands include:
Command	Description
whoami	Brief bio and current status (Student @ Trakya Uni)
skills	Technical stack (C, Assembly, VHDL, etc.)
projects	Details on my Disassembler and System projects
contact	GitHub, LinkedIn, and Email information
cv	Direct link to my Europass Resume
clear	Clears the terminal screen
Installation & Usage

Since this is a client-side project, no server setup is required.

    Clone the repository:

    git clone https://github.com/mecik-arda/Interactive-Terminal-Portfolio.git

    Open index.html in any modern web browser.
